CanvasForge macOS Intel DMG is attached to this release as a real disk image.

Download: CanvasForge-0.6.0-beta.12-macos-x64.dmg
(not this text file)

Requires an Intel Mac and macOS 11+ (verified on Monterey 12.7.6).
Open the DMG and drag CanvasForge to Applications.
First launch may need right-click → Open (ad-hoc signed, no Developer ID).
Capture may prompt for Screen Recording and Accessibility.

Apple Silicon is not a real build yet.

Install notes: https://github.com/lukejmorrison/canvasforge#macos-intel
Roadmap: https://github.com/lukejmorrison/canvasforge/blob/master/ROADMAP.md
