# CanvasForge mobile

The phone app is the Flutter project in [`app/`](app/). iOS and Android share that Dart codebase. See [`app/README.md`](app/README.md) and [docs/mobile-pairing.md](../docs/mobile-pairing.md).

The HTML files in this folder are a fallback capture page the desktop can still serve on the LAN if the Flutter app is not installed. They are not the product.
